# SpeakNow 3D 场景精修 · 2026-10-11

沿用 `audit/2026-10-11/evidence/prompt-history.json` 中已有的空间视觉方向：品牌配色、自然光影、克制动效、清晰交互、移动端与 WebGL 降级。此次范围为现有十二个场景及其共同渲染器。

## 已完成

| 发现的问题 | 修改 | 范围 |
| --- | --- | --- |
| 木纹材质工具已有，但实际地板与多数木家具没有使用 | 地板与木家具接入确定性纹理及轻微凹凸；座椅接入织物，吧台台面接入石材 | `roomMaterials.js`、`buildRoom.js` |
| 金属没有环境反射，材质区别不够清楚 | 本地生成预过滤环境贴图；控制环境强度、曝光和粗糙度 | `createScene.js` |
| 植物、座椅等家具落地感不足 | 共用一张径向透明纹理添加柔和接触阴影，保留原有方向光阴影 | `buildRoom.js` |
| 夜间主要改变全局亮度 | 窗外渐变天色、暖色吊灯、灯泡自发光、环境背景与反射强度一起响应既有日夜开关 | `buildRoom.js`、`createScene.js` |
| 物件选择只表现为悬浮标记 | 仅克隆可交互物件的材质，增加轻微选中高亮，避免共享材质连带改变其他物件 | `buildRoom.js` |
| 场景操作部分只有 32–38px | 镜头、日夜、展开与旋转缩放按钮至少 44px | `scenario-studio.css` |
| 隐藏后恢复会带入之前的帧间隔 | 隐藏与离开视口时重置帧时钟 | `createScene.js` |

## 保留与性能边界

保留十二个场景、三十六个任务提示、镜头视角、键盘与触屏输入、场景展开、降级重试和真实练习入口。此次没有修改录音、AI、评分、API 或用户数据。

纹理、阴影贴图和环境反射均在本地生成，无远程模型、新图像服务或新增依赖。环境贴图仅在场景初始化时生成；材质和接触阴影不新增持续动画。延续静态场景按需渲染、动态场景约 30fps 上限、离屏暂停、降低动态效果和卸载资源清理。新增环境渲染目标加入原有销毁流程。

环境贴图和接触阴影增加了初始化和绘制成本；未测量真实设备的 FPS、GPU 内存或性能提升比例。
