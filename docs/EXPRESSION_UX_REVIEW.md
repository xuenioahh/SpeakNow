# 视频表达习惯功能：用户任务体验走查

日期：2026-09-18

## 方法与边界

从 `/voice` 的功能入口开始，在独立 Chrome 会话中执行录制、回看片段、确认习惯、A/B 练习、保存及重新进入的用户任务。检查桌面 1440 × 1000 和手机宽度 390 / 320 的页面布局，并查看截图。

浏览器、页面交互、MediaRecorder、Blob 视频播放和本地保存是真实执行的。登录身份、摄像头/麦克风输入、视觉测量及模型服务失败使用测试替身；未接触真实账号、个人摄像头或生产数据。这是基于用户任务的体验走查，不是招募真人后的可用性研究，也不验证动作识别准确率、真实转写质量或教育效果。手机尺寸检查不等同于 iOS Safari / Android 真机测试。

## 发现与修改

| 用户任务 | 发现 | 修改 |
| --- | --- | --- |
| 第一次开始录制 | 桌面初始截图中，开始按钮在大块视频预览下方，首屏看不到主要操作 | 将录制操作移到预览上方 |
| 录完后找分析 | 页面停在录制位置；复盘区在下方，手机还需要经过整块习惯笔记 | 完成录制后将视口和键盘焦点移到复盘区；第二次录制后移到 A/B 练习区 |
| 回放后继续标注 | 片段按钮把人带回顶部播放器，缺少返回原卡片的操作 | 新增“Back to this moment”，返回并聚焦对应卡片 |
| 无自动转写时开始练习 | “Practise this moment”不可用，附近没有解释 | 就地提示先补充说过的话；复盘区解释反思问题与练习的文字前提 |
| 无自动转写时保存 A/B 心得 | 选好偏好、填写心得后保存按钮仍不可用；第二段文字要到另一个区块补充 | 在 A/B 区直接编辑第二段文字，并逐步提示缺少文字、同义确认、偏好或心得；修改文字后重新确认同义 |
| 实验尚未填写意图时重录 | 顶部录制入口可绕过练习面板的意图要求 | 统一入口要求，使用“Record another take”并解释意图前置条件 |
| 反思问题服务不可用 | 原错误提示写到顶部录制面板，远离触发按钮 | 在反思问题操作旁显示错误，保留重试能力；旧会话错误不污染新会话 |
| 已有视频后再次申请摄像头失败 | 错误分支回到初始状态，使原复盘界面消失（代码检查发现） | 有旧视频时恢复复盘状态，保留原视频、文字及下载入口 |

## 回归脚本

`scripts/check-expression-browser.cjs` 使用独立测试会话，不修改真实用户数据。先启动前端，然后运行：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
CHROME_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
node scripts/check-expression-browser.cjs
```

如果 Playwright 已可直接加载，可省略 `PLAYWRIGHT_MODULE`。`SPEAKNOW_TEST_URL` 默认 `http://127.0.0.1:5173`；`SPEAKNOW_TEST_ARTIFACTS` 默认 `/tmp/speaknow-experience`。浏览器检查包括实际片段播放时间、焦点位置、筛选结果、保存前置条件、记录持久化及错误恢复。截图和通过项清单输出到上述产物目录。

## 本轮结果

- Chrome 153.0.8010.48：12 项浏览器检查通过，未出现未捕获的页面异常。
- 完整走通：入口 → 录制 → 复盘 → 确认/排除习惯 → 第二次录制 → A/B 回放 → 补充文字 → 保存心得 → 刷新后读取/删除。
- 故障路径通过：首次拒绝摄像头后重试、视觉观察不可用、没有自动转写、模型服务失败、再次录制申请权限失败后保留旧内容。
- 390px 和 320px 的复盘及 A/B 页面均无横向溢出；已人工查看首屏、手机 A/B 及证据不足状态截图。
- `npm run lint`、`npm run build`、三组已有分析/练习/API 回归脚本及 `git diff --check` 均通过。

## 仍需真人验证

- 用户能否从 “The Expression Lab” 入口理解这也提供视频表达习惯复盘；当前入口更强调练习实验。
- 首次用户能否区分“我确认过的例子”和“跨至少三次会话形成的模式”，是否觉得等待成本太高。
- 在普通光照、眼镜、遮挡和不同口音下，真实视觉观察及转写是否足以让用户愿意修正文稿并完成第二次录制。
- 手机真机上的摄像头权限、竖屏取景、软键盘遮挡与视频编码兼容性。

建议下一轮邀请 3–5 位第一次使用的人独立完成“录一段 30 秒说明，找到一个习惯片段，再尝试一个改动”的任务，观察卡住位置、所需提示与完成情况；这些工作尚未执行。
