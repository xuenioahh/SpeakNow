## 路演可用表述

“我们已通过 DeepSeek API 原始 usage，对 IELTS、TOEFL 和日常对话各进行了三组工程实测。按当前高峰价格，并保守假设所有输入均未命中缓存，单次文本模型成本分别约为 0.0262 元、0.0087 元和 0.0401 元。Daily 样本为六轮对话加反馈；这些数字仅覆盖模型推理，语音和基础设施成本另计。”

## 样本定义与边界

- IELTS：既有 demo 完整模拟题；12 条人工编写工程回答，12 次真实考官过渡语生成，加 1 次整套反馈。每次考官请求携带已有回答；反馈含实际生成的考官语句。
- TOEFL：既有 2026 模拟题；7 条跟读转写加 4 条访谈回答，合并调用一次真实反馈。题目为已有固定内容，没有假设每题都会调用考官模型。
- Daily：6 条人工编写用户回答，6 次有历史上下文的真实流式对话，再生成 1 次整段反馈。没有把六轮等同于六分钟。
- 每个场景重复测试 3 次相同输入骨架，AI 输出由服务实际生成。重复请求会增加缓存命中；样本不代表三位真人、真实用户分布或置信区间。
- 未采集实体麦克风、ASR、付费 TTS、摄像头计算、服务器、数据库、存储、带宽、税费和支付费。不能据此宣称总成本、毛利率、整场真人考试成本或分钟成本。
- 实际供应商重试均会留下独立回执。本轮请求情况见明细；未来长对话、较长答案或失败重试可能增加成本。未将已清空的内部测试历史当作全站累计使用量。

## 价格与算法

价格于 2026-11-05 核对：[DeepSeek 官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。单位：人民币/百万 Tokens。

| 模型 | 命中输入（空闲/高峰） | 未命中输入（空闲/高峰） | 输出（空闲/高峰） |
|---|---:|---:|---:|
| deepseek-flash | 0.02 / 0.04 | 1 / 2 | 4 / 8 |
| deepseek-v4-pro | 0.15 / 0.30 | 4.5 / 9 | 13.5 / 27 |

单次成本 =（prompt_cache_hit_tokens × 命中单价 + prompt_cache_miss_tokens × 未命中单价 + completion_tokens × 输出单价）÷ 1,000,000。Input = prompt_tokens；Output = completion_tokens。若 usage 有 reasoning_tokens，已包含于 completion_tokens，不额外叠加。

“全未命中高峰”只替换输入缓存条件和单价，保留这批实际观测到的输入/输出 Token 数；这是保守价格情景，不是未来请求成本的上限。

## 3D 日常口语：识别与成本边界

| 环节 | 当前实现 | DeepSeek Token 成本 | 验证状态 |
|---|---|---|---|
| 3D 场景、NPC 与 Orb | 浏览器本机渲染 | 渲染本身不调用 DeepSeek | 代码核查；设备算力、耗电与资源下载带宽未计价 |
| 摄像头脸部、姿态、手部 | 本机 Worker 中的 MediaPipe Face/Pose/Hand Landmarker | 逐帧识别本身不调用 DeepSeek | 模型与代码已核查；本轮成本样本未开启真人摄像头 |
| 语音转文字 | 浏览器 SpeechRecognition；本地 Whisper 路径正在修复 | 不属于 DeepSeek usage | 浏览器服务无本站账单收据；Whisper 模型尚未成功下载，不能宣称本地转写已可用 |
| NPC 对话 | deepseek-flash | 本轮 Daily 实测包含 6 轮 | 三组真实 usage |
| 整段反馈 | deepseek-v4-pro | 本轮 Daily 实测包含 1 次 | 三组真实 usage；未携带真实摄像头观测样本 |
| 配音 | 本地版配置为浏览器 speechSynthesis；付费 ElevenLabs 为可选路径 | 不属于 DeepSeek usage | 本轮未测付费配音账单 |

因此，Daily 的 ¥0.0401/次是六轮文字对话加一份文字反馈的平均保守价格情景，不能称为完整 3D 音视频会话总成本。将摄像头结构化观测附加到最终反馈时，可能增加输入 Token，必须再从该请求的真实 usage 统计；不能默认增量为零。发音评分属于另一条 Azure 声学评估路径，不能用转写文字或摄像头观测替代。
