## 审计与实施

| 当前元素 | 问题 | 处理方式 | 原因 |
|---|---|---|---|
| Practice review / 标题 / listen-repeat | 重复及内部枚举 | 单一主标题；考试与已回答数一行 | 区分题号与已回答进度；quick 使用 1/1 |
| Saved on this device…长提示 | 保存、登录与风险混合 | Saved locally / Synced to your account / Sync failed；统一同步入口；Save details | 成功状态须有实际保存结果 |
| No AI feedback yet…与占位改进 | 空框架、重复引导 | 未生成只显示一个反馈操作及能力边界；隐藏 Performance 与 Improvements | 回答优先；按钮本身清晰表达未生成状态 |
| Your answers and recordings 折叠 | 实际回答不可见 | 默认展示原题、回答、可用播放器 | 不再让用户先看系统说明 |
| Reference 与重复 diff 类别 | 原句重复、差异被折叠 | 原句只保留一处；回答下方默认展示漏词、增词、可能替换及词序 | 差异是学习核心；不冒充发音评估 |
| 替换词配对 | 全局漏词与增词可能跨位置错配 | 只在相邻匹配词之间配对，词序变化仍标为可能 | 不把句首漏词和句尾增词误判成替换 |
| TOEFL / IELTS assessment context | 背景信息与本次表现混杂 | 从 Review 移除 | 不影响反馈与重练，无官方评分 |
| Speech evidence and limits | 短样本衍生语速、filler 零值 | 移除统计面板，不新增统计门槛 | 当前未验证任何可靠语速样本门槛，因此不展示该指标 |
| 无转录 / 录音缺失 | 空转录被声称有录音，反馈区域重复解释缺少转录 | 分别显示 No transcript available / No recording saved / Recording unavailable；全无转录时隐藏反馈区域 | 准确反映已知数据，不猜测失败原因；直接重练 |
| LearningAudio | 播放错误不呈现、重试缺失 | 仅 Blob 可用时渲染；加载、播放失败均可重试；可访问名称含回答编号 | 不留下空播放器；清理旧对象 URL |
| Key Improvements | 后端强制至少一条，重复项和无效链接可能存在 | 接受 0–3 条；UI 去重、验证引用；回答旁链接共用同一筛选结果 | 不凑建议，不产生无目标的反馈链接 |
| Practice Again | 同步混入核心流程 | 同步集中在顶部；反馈前突出反馈，反馈后突出重练 | 同屏只有一个强调主按钮 |
| 前后比较 | 当前回答重复展示 | 前次真实回答与录音、当前回答定位链接 | 保留真实关联，避免重复整份当前回答 |
| Camera evidence | 无数据仍显示多个空项 | 只在实际指标存在时折叠显示 | 保留已保存测量数据，不凑空面板 |
| Manage saved practice 长说明 | 高噪声、确认非对话框 | 低优先级 Delete practice；Radix 确认对话框 | 清楚说明不可逆范围、共享音频保留及关联依赖 |
| 云端反馈读取 | 云端数据被误标成本地反馈 | 依据服务端返回反馈设置反馈同步标志 | 修复真实状态错误 |

必要提示保留：文本反馈能力边界、录音/转录真实异常、操作错误及重试、保存位置及失败状态、按需保存风险、删除确认中的实际范围。反馈状态通过 live region 通知；删除失败保留在对话框内；比较、折叠和播放器有可访问名称。

## 已知限制与未验证范围

现有持久化数据没有转录失败原因字段，空转录只能准确显示“没有可用转录”，不能事后区分识别失败或无识别结果。本次保留数据结构，未虚构失败原因。识别文本可能有误，diff 为文本比较。AI 仅评估转录，无发音、停顿或官方分数。自动测试使用受控模型返回，不是生产模型质量评测；未向真实账户写入数据，未部署线上。没有遗留的本次页面功能阻塞问题。
