# SpeakNow 反馈标准

## 1. 目标与证据

像认真看过本次回答的老师，而不是设备报告或鼓励模板。每段反馈必须回答一个问题：这次哪里有效、哪里值得改、下一次具体怎么说。不得凭文字声称听出了发音、停顿、语速或自信；不得用“很好，继续练习”等无依据评价填满版面。

## 2. 默认阅读顺序

1. 1–2句总结本次回答的内容与最优先改进点；直接称呼you，不写系统已生成报告等状态废话。
2. 最多2个有原话依据的优点；没有证据就省略。
3. 最多3个按收益排序的改进：原话 → 为什么影响意思/任务 → 可直接使用的表达 → 一次可完成的重试任务。单题默认只强调1个重点。
4. 录音、来源、测量限制、技术指标默认折叠；只在确实阻止使用时显示错误和恢复按钮。

## 3. 范围必须分开

| 场景 | 默认反馈 | 禁止 |
| --- | --- | --- |
| 单句跟读 | 原句与实际转写的遗漏/替换/添加，定位到词，给短语级重试 | 把ASR词差异当成发音错误或音素评分 |
| IELTS/TOEFL单题练习 | 当前题目的实际回答、一个重点及改写示例；不结束整组即可查看 | 用一题推断整组/整场表现 |
| 七句跟读整组 | 基于已答题的总体结果、重复出现的词句问题、优先重练题号 | 简单拼接七份单题报告；未答完称完整整组 |
| IELTS整场/多题访谈 | 对比实际已答题的共性及不同部分任务完成情况 | 虚构未答题表现、正式考试分数 |
| Daily | 对方真正回应了什么、表达哪里顺畅、下一句可以怎样更自然 | 强行回到场景清单、机械每轮提问、把NPC话当用户优点 |
| 摄像头/表达/Presentation | 可观察证据、时间或原话、与本任务有关的练习 | 仅凭landmark评价心理、情绪、自信 |
| 录音检查 | 有问题才给调整动作；正常录音不占据主反馈位置 | 用响度/静音比例替代语言反馈 |

## 4. 练习与考试行为

- Practice：录完当前题可立即查看单题反馈，可“Try again”保留当前题目和已完成其他题；改录/编辑后不能显示旧反馈。
- Exam：不在作答过程中提供辅导、任意重录或揭示参考句；交卷后分析。
- 两种模式都有保存退出和退出不保存。后者必须确认，仅丢弃本次未完成草稿及其不共享录音，不删其他历史练习；停止捕获与播放，等待在途本地保存后再清理，防止退出后草稿复活。
- 单题即时反馈不生成独立历史尝试、不要求先云保存；服务失败保留当前回答，可重试。模型调用仍记真实用量，不能假称无费用。

## 5. 验收

测试覆盖单题立即反馈、不用完成七题、重试后旧反馈失效、整组范围标签、考试模式不泄露辅导、退出不保存后刷新无草稿、录音指标默认折叠。真实模型反馈另行抽查，Mock只验证流程。旧历史反馈不静默改写、不批量触发付费重算。
