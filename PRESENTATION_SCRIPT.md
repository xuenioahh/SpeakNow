# 1-Minute Project Introduction

Hello everyone, our project is **SpeakNow**, a local-first speaking practice web application built for ENT208TC Session 4 Group 25.

The goal of SpeakNow is to help users improve spoken communication in two practical settings. The first is **scenario-based voice practice**, where users can enter a conversation context, speak through a task, and then review feedback and performance reports. The second is **presentation rehearsal**, where users can practise slide-based speaking, receive pause-time guidance, and review presentation analysis afterwards.

From a technical perspective, we built the project with **React**, **Vite**, and **Tailwind CSS**, and structured it so the application can still run in a **local-first** way. That means reviewers can use the system without depending on a fully deployed backend, while still seeing the main interaction flows, reporting logic, and user progress features.

Overall, SpeakNow is designed as a practical communication training platform that combines guided speaking practice, presentation coaching, and progress tracking in one integrated product.
