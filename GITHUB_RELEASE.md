# Suggested GitHub Release

## Release Title

`SpeakNow Coursework Release v1.0`

## Release Body

SpeakNow is a local-first speaking practice web application developed for `ENT208TC Session 4 Group 25`.

Team members:

This release presents the project as a standalone coursework deliverable focused on two main workflows:

- scenario-based voice conversation practice
- presentation rehearsal and feedback

### Included in this release

- local register and login flow
- protected application routes
- voice practice scenarios and session flow
- presentation practice pages and analysis flow
- history and report pages
- local-first persistence and fallback behavior

### Technical stack

- React
- Vite
- Tailwind CSS
- TanStack Query
- Radix UI / shadcn-style components

### Demo

- Live demo: `https://omniverse-ent208.vercel.app`
- Repository: `https://github.com/xuenioahh/SpeakNow`

### Notes

This version is designed to be easy to review and demonstrate. The app keeps a usable local workflow so the main product experience can still be explored without requiring a fully managed backend deployment.
